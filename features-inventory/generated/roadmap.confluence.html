OpenELIS Global — product roadmap

The HIE-ready laboratory platform. Open-source OpenELIS Global runs every core workflow across clinical, environmental, and vector testing — and speaks FHIR R4 to the rest of your health system.

FHIR R4 interoperability
EMRs, registries, dashboards

Broad analyzer integration
ASTM, HL7, flat file, pipeline

Deploy as an HIE, out of the box
OpenHIM, OpenCR, OpenMRS, GOFR

Clinical, environmental & vector
All core lab workflows

How we release

OpenELIS Global ships continuously. The platform is production-ready and updated regularly; each capability above carries its own maturity, independent of any single release or date.

Version tags follow Major.Minor.DevState.Fix (e.g., 3.1.3.1), where DevState is 0=alpha, 1=beta, 2=release candidate, 3=release.
