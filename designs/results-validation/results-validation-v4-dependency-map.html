How to use this at breakdown (PR-sized slices):
  • Configuration ships first. It has no upstream dependency in this set (only Role/Permission + lab_unit.domain, both present) and supplies the policy + flags both other pages read.
  • Results Entry and Validation can start on their dependency-light slices — the table, panel hierarchy, edit-state, Method/Analyzer split, notes, this-analysis History, triage view, guarded release — none of which need the red nodes.
  • Gate the red-node features. Reagent capture (v2.1), control capture + the QC-fail signal, partial sample use, used-up→disposal, and interpretation rules each wait on an unbuilt dependency. They should be later slices, gray-stated until their dependency lands — not in the first shippable cut.
  • Cross-cutting: the QC-fail Clear-lane input and the control capture share the same dependency (manual/RDT control persistence) — build it once, it unblocks both pages.
