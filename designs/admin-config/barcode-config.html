Barcode Configuration

Configure how barcode labels are generated for the two system-default label types every OpenELIS deployment uses — Order and Specimen. Additional label types (Block, Slide, Freezer, site-specific) are managed in Label Presets under OGC-285.

Number Bar Code Label

Indicate the default number of bar code labels which should be printed with every order and specimen.

Default Bar Code Labels

The default value pre-fills the Labels section in Order Entry. Users may override the default per order, up to the maximum.

Maximum Bar Code Labels

The maximum number of labels that may be printed for a single order or specimen. Once reached, users cannot print additional labels of that type.

Bar Code Label Elements

Check the box next to the optional elements that should appear on bar code labels. Lab Number is always included.

Appendix B — Post-Save Print Dialog (Editable Quantities)

OGC-285 · v2 preview

When the order is saved and a lab number is assigned, this modal appears with one row per active label type. Each row's quantity is editable inline before printing — useful if the tech entered the wrong count at order entry and needs to correct it (e.g., scaling up Specimen labels to match the actual number of aliquots being created). Each Print button opens a separate PDF in a new tab so the user can swap label stock between print jobs.

You can adjust quantities here if needed before printing — e.g., if you'll create 4 aliquots, set Specimen Labels to match.
