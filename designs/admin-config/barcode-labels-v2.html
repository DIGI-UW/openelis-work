Label Presets

Define reusable label templates. Each preset specifies dimensions, barcode type, and the content fields rendered on the label. Test catalog entries link to one or more presets to drive automatic label generation at order time.

System presets are protected
Order, Specimen, Block, Slide, and Freezer labels are system presets — they can be edited but not renamed or deactivated. Custom presets can be freely created, edited, duplicated, or deactivated.
